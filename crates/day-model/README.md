# day-model

Observe individual fields and collection entries in a Day application model.

[Day](https://daybrite.dev/docs/) is a Rust framework for building apps with native desktop and
mobile controls, plus HTML controls on the web.

It tracks which properties a UI reads, so changing one field updates its readers without waking
every observer of the whole store. Typed accessors are generated by
[`day-macros`](https://github.com/daybrite/day/tree/main/crates/day-macros).

Enable the `model` feature of [`day`](https://github.com/daybrite/day/tree/main/crates/day) for
application use. The model guide explains stores, bindings, transactions, and when property-level
observation is useful.
