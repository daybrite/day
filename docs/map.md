# Maps

Day currently provides no map control. The prototype map package and its Showcase page have
been removed. No replacement API or external map package is maintained in this workspace.

Applications that need maps must supply their own integration. The [native piece
extension guide](/contributing/tutorials/native-piece) explains how to host a platform view;
it does not provide mapping, geocoding, routing, or provider credentials.

Device coordinates remain available through the separate [location service](/docs/reference/location).
