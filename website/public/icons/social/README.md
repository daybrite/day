# Social icons

The GitHub, LinkedIn, Mastodon, and classic Twitter bird SVGs come from
[Bootstrap Icons v1.11.3](https://github.com/twbs/icons/tree/v1.11.3/icons).
They are distributed under the adjacent MIT license. Brand marks belong to their owners.

Register bundled icons in `src/resources.json` and run `npm run strings:generate` to update
the generated `res.vectors` constants used by the social links.
