# Explain a specific design question

Authoring template: replace the guidance below before publication.

## Question and scope

Name the question, audience, implementation status, and assumptions.

## Mental model

Define terms by linking to the shared glossary. Describe the objects and their relationships.

## Mechanics

Explain how the model works against current implementation evidence. Include lifecycle and threading where relevant.

## Tradeoffs and alternatives

Describe benefits, costs, limitations, and why the current design was chosen. Distinguish proposals from shipped behavior.

## Diagram or example

Add a diagram only if it clarifies the model. Supply a text equivalent; label conceptual snippets as non-runnable.

## Related tasks and reference

Link to procedures and exact contracts instead of duplicating them.
