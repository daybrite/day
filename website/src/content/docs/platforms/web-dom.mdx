`web-dom` compiles a Day app to WebAssembly and presents controls as HTML elements. It is a
[Tier 3 · Experimental](/docs/reference/platforms#support-tiers) target. Use the
[Web guide](/docs/how-to/web) to build, run, test, and publish an app.

## Requirements

A UI-only app needs the `wasm32-unknown-unknown` Rust target, which Day installs when missing.
Persistence also needs a WebAssembly-capable C compiler and a host with the required response
headers. See [System requirements](/docs/reference/system-requirements#web) and
[Persistence](/docs/reference/persistence#the-web).

## Browser limitations

- Browser permissions, secure-context rules, and user-activation requirements apply to clipboard,
  location, sensors, file pickers, and fullscreen requests.
- Additional app windows use covers within the page. Desktop window placement and content
  protection are unavailable.
- Lists build visible rows plus overscan; previously visited rows retain their elements.
  Test memory use with the size of collection your app displays.
- HTTP is asynchronous and subject to CORS. Synchronous data-file reads and blocking HTTP
  calls are unavailable.
- Optional pieces and parts have their own browser support. Consult the individual component
  pages, including [Web view](/docs/reference/webview), [Media](/docs/reference/media), and
  [Lottie](/docs/reference/lottie).

HTML semantics and Day's accessibility annotations supply the browser accessibility tree.
Check keyboard operation and assistive technology with the controls and browser combinations
your app uses; a native build does not validate the browser experience.

## What each piece becomes

The generated [coverage matrix](https://github.com/daybrite/day/blob/main/docs/coverage-matrix.md), checked in CI, covers every toolkit;
this table adds links and notes.

| Day piece | HTML |
|---|---|
| [`column`](https://docs.rs/day-pieces/latest/day_pieces/fn.column.html) / [`row`](https://docs.rs/day-pieces/latest/day_pieces/fn.row.html) / [`nav_stack`](https://docs.rs/day-pieces/latest/day_pieces/fn.nav_stack.html) / [`section`](https://docs.rs/day-pieces/latest/day_pieces/fn.section.html) | [`<div>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/div) |
| [`label`](https://docs.rs/day-pieces/latest/day_pieces/fn.label.html) | [`<div>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/div) (not a `<label>`) |
| [`button`](https://docs.rs/day-pieces/latest/day_pieces/fn.button.html) | [`<button type="button">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button) |
| [`toggle`](https://docs.rs/day-pieces/latest/day_pieces/fn.toggle.html) | [`<input type="checkbox">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/checkbox) styled as a switch |
| [`slider`](https://docs.rs/day-pieces/latest/day_pieces/fn.slider.html) | [`<input type="range">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/range) |
| [`text_field`](https://docs.rs/day-pieces/latest/day_pieces/fn.text_field.html) | [`<input type="text">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/text) |
| [`secure_field`](https://docs.rs/day-pieces/latest/day_pieces/fn.secure_field.html) | [`<input type="password">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/password) |
| [`text_area`](https://docs.rs/day-pieces/latest/day_pieces/fn.text_area.html) | [`<textarea>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/textarea) |
| [`picker`](https://docs.rs/day-pieces/latest/day_pieces/fn.picker.html)`()`[`.menu`](https://docs.rs/day-pieces/latest/day_pieces/trait.PickerBuilder.html#tymethod.menu)`()` | [`<select>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/select) with `<option>`s |

| [`progress(f)`](https://docs.rs/day-pieces/latest/day_pieces/fn.progress.html) | [`<progress max="1">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/progress) |
| [`spinner()`](https://docs.rs/day-pieces/latest/day_pieces/fn.spinner.html) | a CSS-animated `<div>` |
| [`divider`](https://docs.rs/day-pieces/latest/day_pieces/fn.divider.html) | `<div>` |
| [`scroll`](https://docs.rs/day-pieces/latest/day_pieces/fn.scroll.html) | `<div>` with `overflow:auto` |
| [`list`](https://docs.rs/day-pieces/latest/day_pieces/fn.list.html) | scrolling `<div>` of absolutely positioned cells |
| [`nav`](https://docs.rs/day-pieces/latest/day_pieces/fn.nav.html) / `nav_menu` / `tabs` | `<div>`s (with `<button>`s for the tab strip and back control) |
| [`image`](https://docs.rs/day-pieces/latest/day_pieces/fn.image.html) | [`<img>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img) |
| [`vector`](https://docs.rs/day-pieces/latest/day_pieces/fn.vector.html) | [`<img>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img) loading the staged SVG: day-toolkit-dom requests `.svg` for names in the page's vector list, and the browser renders it at display size; the raster PNG sits beside it as the older-host fallback |
| [`canvas`](https://docs.rs/day-pieces/latest/day_pieces/fn.canvas.html) | [`<canvas>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/canvas), display list replayed on a 2-D context |
| dialogs / alerts / prompts | [`<dialog>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog) via `showModal()` |
| *external* `media()` | [`<video>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video) |

Text uses browser font preferences and the toolkit's desktop or touch-device scale. Page zoom
applies as usual. Canvas text remains in drawing coordinates. Scrolling uses browser scroll
containers, and browser-managed panes report their sizes to Day's layout system.
