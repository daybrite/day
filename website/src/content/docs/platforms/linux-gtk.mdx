`linux-gtk` renders GTK 4 widgets styled by [libadwaita](https://gnome.pages.gitlab.gnome.org/libadwaita/),
through [`gtk4-rs`](https://gtk-rs.org). It is the default recommendation on Linux: it's the
toolkit Ubuntu, Fedora and Debian install by default.

## Getting started

GTK 4.10+ and libadwaita 1.5+ are required (Ubuntu 24.04 and Fedora 40 both satisfy this):

```sh
sudo apt install libgtk-4-dev libadwaita-1-dev pkg-config   # Debian/Ubuntu
sudo dnf install gtk4-devel libadwaita-devel pkgconf        # Fedora

cargo install day-cli
day new app my-app --toolkit linux-gtk
cd my-app
day launch -p linux-gtk
```

Add `libwebkitgtk-6.0-dev` if you use the web view piece. `day doctor --toolkit gtk` probes
GTK 4, libadwaita, `glib-compile-resources`, and the packaging tools (`flatpak-builder`,
`linuxdeploy`, `linuxdeploy-plugin-gtk`); it does not check WebKitGTK.

```sh
day pack -p linux-gtk        # single-file .flatpak AND a portable .appimage
```

`day pack` produces both formats by default. The flatpak runtime supplies GTK itself
(`org.gnome.Platform`), so that bundle carries your app and its assets, not the toolkit —
`flatpak install ./my-app-1.0-linux-gtk-x86_64.flatpak` is all a user needs. The AppImage carries
its own GTK: `chmod +x` and run, no package manager involved.

## Caveats and special considerations

- **libadwaita is not optional.** The window, navigation, tabs, dialogs and animations are all
  Adwaita types; a plain-GTK build is not a supported configuration.
- **`GtkVideo` needs a GStreamer media backend** in the GTK build. Distro packages ship one;
  Homebrew's gtk4 does not, so the media piece shows GTK's own "no media backend" error on
  `macos-gtk`.
- **No Lottie, no map** on this backend — each renders its placeholder. `cover()` presents as
  a topmost window-sized child (no transition, programmatic dismissal only).
- **The combo box uses `GtkComboBoxText`**, deprecated in GTK 4.10 but kept deliberately: no
  editable replacement exists yet.
- **A `progress` node picks its widget at realize time** — `progress(f)` becomes a `GtkProgressBar`
  and `spinner()` a `GtkSpinner`. A node that starts indeterminate will not turn into a bar on a
  later value change; use separate nodes if you need both.
- **Canvas text uses cairo's toy text API**, not Pango, so complex-script shaping inside a
  `canvas` is weaker than in a `label`.
- GTK on macOS and Windows (`macos-gtk`, `windows-gtk`) exists for development convenience only —
  no packaging, and no accessibility tree (GTK's a11y bridge is Linux-only).

## What each piece becomes

| Day piece | GTK widget |
|---|---|
| `column` / `row` / `stack` / `section` | [`GtkFixed`](https://docs.gtk.org/gtk4/class.Fixed.html) (Day owns layout) |
| `label` | [`GtkLabel`](https://docs.gtk.org/gtk4/class.Label.html) |
| `button` | [`GtkButton`](https://docs.gtk.org/gtk4/class.Button.html) |
| `toggle` | [`GtkSwitch`](https://docs.gtk.org/gtk4/class.Switch.html) |
| `slider` | [`GtkScale`](https://docs.gtk.org/gtk4/class.Scale.html) |
| `text_field` | [`GtkEntry`](https://docs.gtk.org/gtk4/class.Entry.html) |
| `text_area` | [`GtkTextView`](https://docs.gtk.org/gtk4/class.TextView.html) in a [`GtkScrolledWindow`](https://docs.gtk.org/gtk4/class.ScrolledWindow.html) |
| `picker().menu()` | [`GtkDropDown`](https://docs.gtk.org/gtk4/class.DropDown.html) |
| `picker().segmented()` | linked [`GtkToggleButton`](https://docs.gtk.org/gtk4/class.ToggleButton.html)s |
| `picker().inline()` | grouped [`GtkCheckButton`](https://docs.gtk.org/gtk4/class.CheckButton.html)s (GTK 4's radio) |
| `progress(f)` | [`GtkProgressBar`](https://docs.gtk.org/gtk4/class.ProgressBar.html) |
| `spinner()` | [`GtkSpinner`](https://docs.gtk.org/gtk4/class.Spinner.html) |
| `divider` | [`GtkSeparator`](https://docs.gtk.org/gtk4/class.Separator.html) |
| `scroll` | [`GtkScrolledWindow`](https://docs.gtk.org/gtk4/class.ScrolledWindow.html) |
| `list` | [`GtkListView`](https://docs.gtk.org/gtk4/class.ListView.html) (recycling, signal factory) |
| `nav` (split) | [`GtkPaned`](https://docs.gtk.org/gtk4/class.Paned.html) |
| `nav` (stack) | [`AdwNavigationView`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/1-latest/class.NavigationView.html) |
| `nav_menu` | [`GtkListBox`](https://docs.gtk.org/gtk4/class.ListBox.html) (`.navigation-sidebar`) |
| `tabs` | [`AdwViewStack`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/1-latest/class.ViewStack.html) + linked toggle buttons |
| `image` | [`GtkPicture`](https://docs.gtk.org/gtk4/class.Picture.html) |
| `vector` | [`GtkPicture`](https://docs.gtk.org/gtk4/class.Picture.html) showing the raster cache PNG (`.tint` recolors the pixels) |
| `cover()` | emulated: a topmost window-sized child (no transition, programmatic dismissal only) |
| `canvas` | [`GtkDrawingArea`](https://docs.gtk.org/gtk4/class.DrawingArea.html) (cairo) |
| dialogs / alerts / prompts | [`AdwAlertDialog`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/1-latest/class.AlertDialog.html) |
| file dialogs | [`GtkFileDialog`](https://docs.gtk.org/gtk4/class.FileDialog.html) |
| menu bar / context menus | [`GtkPopoverMenuBar`](https://docs.gtk.org/gtk4/class.PopoverMenuBar.html) / [`GtkPopoverMenu`](https://docs.gtk.org/gtk4/class.PopoverMenu.html) |
| *external* `activity()` | [`GtkSpinner`](https://docs.gtk.org/gtk4/class.Spinner.html) |
| *external* `combobox()` | `GtkComboBoxText` (with entry) |
| *external* `search_field()` | [`GtkSearchEntry`](https://docs.gtk.org/gtk4/class.SearchEntry.html) |
| *external* `date_picker()` | [`GtkCalendar`](https://docs.gtk.org/gtk4/class.Calendar.html), in a [`GtkMenuButton`](https://docs.gtk.org/gtk4/class.MenuButton.html) popover when compact |
| *external* `time_picker()` | linked [`GtkSpinButton`](https://docs.gtk.org/gtk4/class.SpinButton.html)s |
| *external* `webview()` | [`WebKitWebView`](https://webkitgtk.org/reference/webkitgtk/stable/class.WebView.html) (WebKitGTK 6.0) |
| *external* `media()` | [`GtkVideo`](https://docs.gtk.org/gtk4/class.Video.html) |

**Text measurement** builds a Pango layout on the label's own styled context rather than calling
`gtk_widget_measure`, because a `GtkFixed` child's size request would otherwise ratchet upward and
never shrink.
